Built for the **SoSoValue Buildathon**, it leverages a state-of-the-art Multi-LLM architecture to turn real-time news and on-chain data into precision trading signals.

---

## 🌟 Core Innovation: The Intelligence Terminal

SoSo SMRE is not just a dashboard; it is an **Agentic Ecosystem**. It doesn't just show you what's happening—it tells you what to do.

### 🧠 Dual-LLM Orchestration
We utilize a specialized dual-brain approach to eliminate AI hallucinations and ensure maximum accuracy:
- **Gemini 2.5 Flash:** Our "Strategy Brain." It handles deep-reasoning, macro-sentiment synthesis, and cross-references breaking news headlines with historical market context.
- **Groq (LLaMA-3.3):** Our "Tactical Brain." It performs lightning-fast technical analysis, volume spike detection, and immediate momentum verification.
- **Automatic Fallback:** If one AI hits a rate limit, the other automatically takes over, ensuring 100% uptime for your Alpha alerts.

### 📡 Today's Alpha: Telegram Alerts
The **Daily Alpha Engine** automatically scans the market 24/7.
- **What it does:** Scrapes top gainers, institutional flows, and news headlines via SoSoValue API.
- **Delivery:** Sends a perfectly formatted "Alpha Report" directly to your **Telegram** with Entry Zones, Profit Targets, and Stop-Loss limits.
- **Dyor Integrated:** Every signal includes a risk-assessment score (Low/Medium/High).

### ⚡ SoDEX Mainnet Execution
We have bridged the gap from information to execution.
- **SoDEX Bridge:** Move from reading a signal to executing a trade on the SoDEX mainnet in seconds.
- **Copy-Trading Ready:** Our architecture supports 1-click execution of AI-generated signals directly into your SoDEX wallet.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- Gemini API Key
- Groq API Key
- SoSoValue API Key

### Installation
1. Clone the repo:
   ```bash
   git clone https://github.com/Cyptoboy777/soso-smre.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Setup Environment:
   Create a `.env.local` file and add your keys (see `.env.example`).
4. Run locally:
   ```bash
   npm run dev
   ```
